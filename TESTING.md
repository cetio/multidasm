# Testing

The test configurations run offline tests with [unit-threaded](https://github.com/atilaneves/unit-threaded). A pre-build step generates the runner at `bin/ut.d`, and each configuration builds and runs its own suite.

## Prerequisites

Install DUB and a D compiler. DUB resolves the `unit-threaded` dependency and generates the test runner automatically.

## Library Build

```sh
dub build --config=library
```

This builds the library without enabling unit tests.

## Running Tests

```sh
dub run --config=test-amd64
dub run --config=test-mips
dub run --config=test-cil
```

Pass a unit-threaded test name after `--` to filter a run:

```sh
dub run --config=test-amd64 -- tests.amd64.arithmetic
```

## Known Defects

Tests below the `// Known defects.` marker in each module describe behavior the assembler does not implement correctly yet. They fail until the underlying defect is fixed. A failing suite is expected while these tests exist; a passing test means its defect has been fixed and the test should be kept as a regression test.

## Test Layout

| Path | Coverage |
| --- | --- |
| `source/tests/amd64/arithmetic.d` | Integer moves, arithmetic, bit tests, and exchanges. |
| `source/tests/amd64/atomics.d` | `lock`, `xacquire`, and `xrelease` prefixes. |
| `source/tests/amd64/branches.d` | Branches, loops, jumps, and label resolution. |
| `source/tests/amd64/cet.d` | CET shadow-stack instructions. |
| `source/tests/amd64/encoding.d` | REX, VEX, and segment prefix encoding. |
| `source/tests/amd64/fpu.d` | x87 floating-point instructions. |
| `source/tests/amd64/memory.d` | Memory operand forms and addressing modes. |
| `source/tests/amd64/simd.d` | MMX, SSE, AVX, and FMA instructions. |
| `source/tests/amd64/stack.d` | Stack operations and stack frames. |
| `source/tests/amd64/system.d` | Flags, fences, privileged instructions, string operations, I/O, and CPUID. |
| `source/tests/mips/core.d` | Integer core, shifts, multiply/divide, and system calls. |
| `source/tests/mips/loadstore.d` | Load and store instructions. |
| `source/tests/mips/branch.d` | Conditional branches. |
| `source/tests/mips/jump.d` | Jumps. |
| `source/tests/cil/constants.d` | Constant-loading opcodes. |
| `source/tests/cil/arithmetic.d` | Arithmetic, bitwise, and shift opcodes. |
| `source/tests/cil/variables.d` | Argument and local variable access. |
| `source/tests/cil/branches.d` | Branches and switch tables. |
| `source/tests/cil/calls.d` | Method calls and returns. |
| `source/tests/cil/objects.d` | Object, token, and array opcodes. |

`bin/ut.d` is generated by each configuration's pre-build command. Don't edit it manually.
